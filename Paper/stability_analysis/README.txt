Note: the code in this section has been repurposed from a paper idea on stability analysis. It will therefore also generate some irrelevant plots for this paper.

By including examples.jl in the julia REPL (include("examples.jl")), you run the julia code. It has the following dependencies:
 - 'Plots' for plotting
 - 'LinearAlgebra' for solving matrix equations
 - 'LaTeXStrings' for latex in plot labels
 - 'Formatting' for some basic formatting

Note: The moving solver results are used for the comoving paper
